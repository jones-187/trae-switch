# 局域网监听功能 - 业务规范文档

## 1. 需求背景与目标 (Why)

为了支持在局域网内访问代理服务，需要新增一个监听局域网的功能开关，使其他设备能够通过局域网访问本地代理服务。

## 2. 功能变更 (What Changes)

### 2.1 界面变更
- 在"系统配置"模块下新增一行"监听局域网"开关（使用 Switch 组件）
- 默认状态为关闭
- 显示当前监听模式状态（开启/关闭）

### 2.2 功能逻辑变更
- 点击开关开启/关闭监听局域网
- 如果当前代理状态为未开始，则只设置值
- 如果当前代理状态为已开始，则设置值后自动重启代理使配置生效
- GetStatus() 返回值中包含 lanMode 状态信息

## 3. 影响范围 (Impact)

- 代理服务器监听地址：从127.0.0.1改为0.0.0.0
- App结构体：新增lanMode字段
- 新增方法：SetLanMode和IsLanMode
- 代理状态管理：增加自动重启逻辑

## 4. 功能清单

| 功能项 | 描述 | 状态 |
|-------|------|------|
| 界面按钮 | 在系统配置模块添加"监听局域网"按钮 | 已实现 |
| 状态管理 | 管理lanMode状态，默认关闭 | 已实现 |
| 代理重启 | 已运行时自动重启使配置生效 | 已实现 |
| 监听地址切换 | 切换代理服务器监听地址 | 已实现 |

## 5. 非目标 (不做什么)

- 不修改其他现有功能
- 不影响代理的其他配置选项
- 不改变代理的核心功能逻辑

## 6. 验收标准

- 界面上成功显示"监听局域网"按钮
- 默认状态为关闭
- 点击按钮后成功开启/关闭监听局域网
- 代理未运行时，设置值后点击开始运行代理，自动应用局域网监听设置
- 代理已运行时，设置值后自动重启代理使配置生效
- 局域网内其他设备能够访问代理服务

## 8. 风险摘要

| 风险类型 | 风险等级 | 描述 | 缓解措施 |
|---------|---------|------|---------|
| 安全风险 | 低 | 监听0.0.0.0可能导致外部网络访问，局域网内其他设备可能未经授权访问代理服务 | 默认关闭，仅在需要时开启；建议在开启时确保防火墙设置正确 |
| 网络风险 | 低 | 可能与局域网内其他服务端口冲突，多设备同时访问可能导致网络拥塞 | 使用默认端口443，确保无冲突；建议在局域网内合理使用，避免过多设备同时访问 |
| 依赖风险 | 低 | 依赖局域网网络连接 | 确保网络连接稳定；在网络不稳定时提供友好提示 |
| 代码风险 | 低 | 需要修改代理服务器监听地址逻辑，需要管理lanMode状态和代理重启逻辑 | 保持代码简洁，添加清晰注释；使用清晰的状态管理机制，确保逻辑正确 |
| 上线风险 | 低 | 可能影响现有代理功能，用户可能误配置导致功能异常 | 进行充分测试，确保现有功能不受影响；提供清晰的界面提示和错误处理 |
