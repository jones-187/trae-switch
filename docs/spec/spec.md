# 局域网监听功能 - 业务规范文档

## 1. 需求背景与目标 (Why)

为了支持在局域网内访问代理服务，需要新增一个监听局域网的功能开关，使其他设备能够通过局域网访问本地代理服务。

## 2. 功能变更 (What Changes)

### 2.1 界面变更
- 在"系统配置"模块下新增一行"监听局域网"按钮
- 默认状态为关闭

### 2.2 功能逻辑变更
- 点击按钮开启/关闭监听局域网
- 如果当前代理状态为未开始，则只设置值
- 如果当前代理状态为已开始，则设置值后自动重启代理使配置生效

## 3. 影响范围 (Impact)

- 代理服务器监听地址：从127.0.0.1改为0.0.0.0
- App结构体：新增lanMode字段
- 新增方法：SetLanMode和IsLanMode
- 代理状态管理：增加自动重启逻辑

## 4. 功能清单

| 功能项 | 描述 | 状态 |
|-------|------|------|
| 界面按钮 | 在系统配置模块添加"监听局域网"按钮 | 待实现 |
| 状态管理 | 管理lanMode状态，默认关闭 | 待实现 |
| 代理重启 | 已运行时自动重启使配置生效 | 待实现 |
| 监听地址切换 | 切换代理服务器监听地址 | 待实现 |

## 5. 非目标 (不做什么)

- 不修改其他现有功能
- 不影响代理的其他配置选项
- 不改变代理的核心功能逻辑

## 6. 验收标准

- 界面上成功显示"监听局域网"按钮
- 默认状态为关闭
- 点击按钮后成功开启/关闭监听局域网
- 代理未运行时，设置值后点击开始运行代理，自动应用局域网监听设置
- 代理已运行时，设置值后自动重启代理使配置生效
- 局域网内其他设备能够访问代理服务

## 8. 风险摘要

| 风险类型 | 风险等级 | 描述 | 缓解措施 |
|---------|---------|------|---------|
| 安全风险 | 低 | 监听0.0.0.0可能导致外部网络访问 | 默认关闭，仅在需要时开启 |
| 网络风险 | 低 | 可能与局域网内其他服务端口冲突 | 使用默认端口443，确保无冲突 |
| 性能风险 | 无 | 对系统性能无明显影响 | - |
